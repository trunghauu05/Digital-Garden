Statement Coverage:
We need at least 2 tests to cover all statements. One test where A > B and another where A <= B to cover both branches of the first IF statement.

Branch Coverage:
There are two branches in the first IF statement (A > B and A <= B) and one branch in the second IF statement (C = D vs. C ≠ D).
To cover all branches, we need 3 tests:
One where A > B and C = D
One where A > B and C ≠ D
One where A <= B and C ≠ D (or C = D)
