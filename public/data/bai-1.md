# 🚀 Bài 1: Giới thiệu về React

React là một thư viện JavaScript tuyệt vời để xây dựng giao diện người dùng.

## 📌 Các khái niệm cốt lõi:
* **Component:** Giống như các mảnh ghép Lego.
* **JSX:** Viết HTML bên trong JavaScript.
* **State:** Trí nhớ của component.
